# APE3 — Organización y entrega

Este directorio contiene **trabajos académicos en preparación**, no hallazgos finales. Ver el [alcance común](alcance-comun.md) y los [issues del repositorio](../../issues).

## Estructura prevista
```text
APE3_Experiencia_Emocional/
├── alcance-comun.md
├── analisis/             # A — análisis de usabilidad y UX
├── curva/                # B — matriz, curva emocional y momentos de verdad
├── mejoras/              # C — heurísticas, tres mejoras y Figma
├── evidencias/           # D — fuentes y protocolo
├── reflexiones/          # D — respuestas preliminares a las tres preguntas
└── informe/              # D — esquema; PDF final en integración
```

Cada responsable trabaja en una rama distinta. A, B, C y D no deben editar los archivos de otros ni el README principal simultáneamente. Las carpetas contienen README de orientación que **no sustituyen** a las entregas. Las puntuaciones y problemas aún no se han evaluado.

La integración final verificará que los datos y hallazgos coincidan, incluirá el comparativo Figma, la matriz y la curva, los créditos por integrante y el enlace GitHub en el informe PDF de **4 a 6 páginas**.
